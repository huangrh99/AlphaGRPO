# Security Policy

## Supported versions

The `main` branch is currently supported.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository.

Do not include vulnerability details, proof-of-concept code, credentials, or exploit steps in a public issue.

Please include:

- the affected commit, file, or configuration;
- the impact and affected users;
- reproduction steps or a proof of concept; and
- a suggested mitigation, if available.

We will acknowledge the report, investigate it, and coordinate disclosure after the issue has been fixed or otherwise resolved.

## Disclosure

Please allow the maintainers reasonable time to investigate and release a fix before making the vulnerability public.
